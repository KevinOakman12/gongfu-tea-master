# 茶道 ChaDao — Путь чая

Веб-приложение для чаепития (гунфу ча): каталог из 106 сортов в 10 категориях (данные из таблиц чайного магазина, метод проливов), расчёт навески под вашу посуду, таймер проливов по готовым таблицам времени, чайный дневник. Свои сорта и правки параметров. Работает офлайн (PWA).

**Открыть:** https://kevinoakman12.github.io/gongfu-tea-master/

На телефоне: откройте ссылку и выберите «Добавить на главный экран» (Chrome, Android) или «На экран Домой» (Safari, iOS). После первого открытия приложение работает без интернета.

## Возможности

- Каталог: категории → сорта, глобальный поиск (название, пиньинь, ноты вкуса).
- Дозировка под объём и материал посуды (фарфор/стекло, исинская глина).
- Сессия: промывка → прогрев → проливы, коррекция «крепковато / слабовато», звуки, экран не гаснет во время отсчёта.
- Свои чаи: правка температуры, граммовки и времён у любого сорта («Сбросить к стандарту»), добавление собственных сортов.
- Избранное: звёздочка на карточке или в панели сорта; избранные сорта показываются отдельным разделом вверху каталога.
- Посуда: на телефоне панель сворачивается в одну строку «100 мл · Фарфор».
- Дневник: оценка, Ча Ци, заметки, повтор сессии; фильтры по сорту, оценке и периоду.
- Статистика дневника: сколько чаепитий, проливов и чая (≈ литров настоя), любимые сорта, динамика оценок.

Все данные хранятся только в браузере (`localStorage`) на этом устройстве.

## Структура

- `index.html` — приложение (HTML + CSS + Vanilla JS, без сборки).
- `assets/tailwind.css` — статический CSS, собранный из классов приложения.
- `assets/fonts/`, `assets/fonts.css` — локальные шрифты (SIL OFL 1.1).
- `manifest.webmanifest`, `sw.js`, `assets/icons/` — PWA и офлайн-режим.

Локальный запуск: любой статический сервер в корне проекта, например `python -m http.server`. Service worker работает только по `http(s)`, не по `file://`.

После изменений состава файлов поднимите `VERSION` в `sw.js`.
